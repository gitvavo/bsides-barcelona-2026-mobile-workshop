Emulator Preparation: Burp and Frida

Import the supplied Burp project settings JSON. Check the proxy listener is running on port 8088 and redirects destination host to 127.0.0.1.

Burp certificate: Edit the listener → Certificate → custom certificate. Browse for the provided .p12 file on your own computer and enter the supplied password. The configuration file does not include a portable absolute path to the certificate.

Android CA: Push the public CA with adb push lab-ca.crt /sdcard/Download/lab-ca.crt. On Android, open Settings → Security & privacy → Install a certificate → CA certificate and select it from Downloads.

Visible Wi-Fi proxy: In Android Settings → Network & internet → Internet → AndroidWifi → Edit → Advanced options, set Proxy to Manual, hostname 10.0.2.2, port 8088, then save. Do not use the separate Emulator Extended Controls upstream proxy. To turn the proxy off, return to Wi-Fi settings and select Proxy: None.

Frida Server: Use a root-capable AOSP emulator. Run these commands after selecting the supplied server binary that matches your emulator architecture and installed Frida version:

adb root
adb shell id
adb push frida-server /data/local/tmp/frida-server
adb shell chmod 755 /data/local/tmp/frida-server
adb shell "/data/local/tmp/frida-server >/dev/null 2>&1 &"
frida-ps -U

Frida Server must be started again after the emulator reboots. Keep the lab certificates and test private key limited to this isolated workshop.

Switch app connection mode

Tap ⚗ Lab Testing inside Mockapp. Select HTTP, HTTPS or HTTPS + pinning, save, then completely force-stop the app and launch it again.

adb shell am force-stop com.mockapp.loyalty
adb shell monkey -p com.mockapp.loyalty -c android.intent.category.LAUNCHER 1

Alternatively use Android Settings → Apps → Mockapp Home Lab → Force stop, then relaunch.
